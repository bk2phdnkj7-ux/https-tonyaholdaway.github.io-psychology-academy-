# Psychology Academy

Starter repository for interactive weekly Introduction to Psychology missions.

## Upload these files exactly as arranged

- index.html
- style.css
- app.js
- missions/week1.html

## GitHub Pages

In repository Settings, open Pages, choose Deploy from a branch, select main and /root, then save.

https://YOUR-USERNAME.github.io/psychology-academy/missions/week1.html
